# Landing-Page ❤️

A clean and simple Landing Page built with HTML, CSS, and JavaScript (jQuery). Designed to showcase products, services, or personal projects in a straightforward way.

✨ Features

Static Layout – Optimized for desktop view.

Clean Design – Minimalist approach to highlight key content.

Interactive Elements – Smooth scrolling and simple animations using jQuery.

🛠️ Technologies Used
HTML5 for semantic structure

CSS3 for styling and layout

JavaScript (jQuery) for interactivity
